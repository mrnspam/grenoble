# Grenoble in één dag

Een mobiele, interactieve dagroute door Grenoble met de Bastille, het historische centrum, de kathedraal en drie keuzes voor de late middag.

De website wordt automatisch gepubliceerd via GitHub Pages bij iedere wijziging op `main`.

## Functies

- sleepbare en zoombare kaart
- drie routevarianten
- klikbare haltes met tijden en toelichting
- routeblokken openen in Google Maps
- volgende stop openen in Apple Kaarten
- responsive ontwerp voor iPhone en desktop

## Lokale preview

Open `site/index.html` in een browser. Voor de kaartbibliotheek is een internetverbinding nodig.
